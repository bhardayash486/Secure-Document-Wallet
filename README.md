\# Secure Document Wallet



A personal digital document management system developed using Java Swing and MariaDB/MySQL.



\## Features

\- User registration and login

\- Secure password hashing

\- Document upload and management

\- Category management

\- Document search

\- Change password

\- Dashboard with document statistics



\## Technologies

\- Java

\- Java Swing

\- JDBC

\- MariaDB/MySQL

\- NetBeans IDE 8.2



\## Database Setup

1\. Start MariaDB/MySQL.

2\. Import `database/document\_wallet.sql` using phpMyAdmin.

3\. Configure the database connection in the Java project.

4\. Open the project in NetBeans and run it.
